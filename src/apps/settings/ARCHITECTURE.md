# AIShell Settings

## Level 0 — What Is This?

The user-facing AIShell Settings app owns personal shell preferences. Its first
surface is the server-backed Markdown keybinding editor at `/settings/keybindings`.

## Level 1 — File Map

- `SettingsContent.tsx` — route-driven settings content and import/export UX
- `settings.css` — token-based, namespaced application styles
- `manifest.tsx` — shell app registration contract
